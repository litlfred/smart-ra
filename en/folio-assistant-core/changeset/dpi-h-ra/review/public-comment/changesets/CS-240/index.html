Support package-based and offline distribution of reference content
requirements
- Define a minimum publication package (usage guidance, examples, test data, limitations, licence, dependencies, support contact, fitness-for-purpose) - Provide caches, mirrors, downloadable packages and offline bundles with version and integrity controls - Describe distribution through downloadable packages, local mirrors and offline bundles as well as live APIs, with version and integrity control - State that terminology may be delivered by caches or synchronised packages, not only live calls - Support APIs, downloadable packages, local mirrors and offline bundles with manifests and dependency resolution - Require the TS to offer a complete expansion or equivalent to consumers - Allow maturity-appropriate terminology delivery (curated lists, versioned packages) before a national runtime service - Describe distributed use patterns for LIMR artefacts in lower-capacity settings
