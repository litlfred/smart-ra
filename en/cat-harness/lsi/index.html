A latent semantic index places every unit of a prose graph — a library section, a skill, a bean — in a space built from which words occur together, so units that discuss the same thing in different words sit close. It is a retrieval aid: every neighbour and finding it reports is a proposal, never a relation the graph asserts.

The method is Latent Semantic Indexing (node lsi), with correspondence analysis (node correspondence-analysis) as its parallel track; how to build, query and audit an index is the skill lsi-indexing.
