Review sheet script

One Google Apps Script runs every review sheet of this document. What is particular to the document is in the sheet's Config tab, which the agent writes and only the sheet's owner can edit.

Set up a sheet

  1. Copy the template for the mode, name it, and share it with the contributors as Editor.
  2. Give the agent the copy's URL; it writes the Config tab.
  3. Data > Protect sheets and ranges > "Ready columns: editors" > Change permissions > Custom: add each editor.
  4. Extensions > Apps Script: paste Code.gs (the only file to paste); save; run installTriggers. Google asks for three permissions: this spreadsheet, the script's own triggers, and its menu.
  5. Drafting only: on the Sections column, tick "Allow multiple selections" in its data validation.

To check a pasted copy: compute the SHA-256 of its text and compare it with the one above. The full steps are in the review-sheet-script skill.
