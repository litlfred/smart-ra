CS-274
title
Define one lifecycle, versioning and impact process for semantic artefacts
requirements
- Establish controlled publication statuses (draft, trial use, normative, deprecated, retired) with permitted uses - Add a common lifecycle from authoring to retirement for models, terminologies and mappings - Add a taxonomy of terminology artefacts and their services - Add dependency, impact and compatibility management as an explicit cross-cutting capability - State version alignment of terminologies and value sets across consuming systems as a conformance expectation - Rename 'minimum dataset' to minimum metadata for governed artefacts - Define version semantics per artefact type, compatibility classification, and version alignment across participating systems - Make dependency tracking and impact analysis mandatory for production-used artefacts
