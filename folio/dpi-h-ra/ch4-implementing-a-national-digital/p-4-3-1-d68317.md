Countries should define and standardise a minimum set of data models for each DPI-H component before implementation begins, regardless of the technology through which those components will be delivered. These minimum data models should specify the mandatory data elements that every implementation supports — the irreducible set of attributes without which a registry, record, or service could not function as shared infrastructure — while allowing national extensions that accommodate country-specific requirements without breaking interoperability with the core. The **logical information model repository** is the designated home for these national data models, and its governance processes are the mechanism through which they are maintained, versioned, and distributed.

Minimum clinical data profiles should also specify how a coded statement preserves its code-system namespace, concept identifier or code, title or display, applicable release, original clinical text, and provenance. For ICD-11, the profile should distinguish Foundation identifiers from MMS codes and specify how the complete postcoordinated expression and any associated concept identifiers are retained and exchanged. The information model should carry the subject, encounter, timing, certainty or verification status, and other required context. When multiple codings are supplied, their relationship must be defined; additional codings must not silently change the meaning or replace a more precise source expression. Derived statistical outputs should be linked to the source statement and the rule version used to derive them.
