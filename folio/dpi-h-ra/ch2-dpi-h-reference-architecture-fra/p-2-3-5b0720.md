Countries should adopt a modular approach, building capabilities incrementally from their current state rather than treating full implementation as a prerequisite for value. As a design principle, this means giving each component clear boundaries and a well-defined interface, so that components are loosely coupled — able to be developed, deployed, replaced, or upgraded independently, without requiring changes to the others that rely on them. A component whose internal workings are entangled with those around it cannot be adopted, adapted, or evolved on its own, which is what modularity is intended to make possible.
