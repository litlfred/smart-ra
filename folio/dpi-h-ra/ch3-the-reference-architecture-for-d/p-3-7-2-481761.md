Each construct is bound to one ArchiMate element type. Section 3.1 establishes the core of the modelling language: the Application Component and Application Service element types, together with the four structural relationships — Realises, Composes, Serves, Accesses — that carry most of the model. Describing conformance and testing calls for a small, self-contained extension to that core — two further element types and two further relationships, used only in modelling behaviour and its evaluation — which this section introduces where they are needed and summarises in Table 3.7.1.
