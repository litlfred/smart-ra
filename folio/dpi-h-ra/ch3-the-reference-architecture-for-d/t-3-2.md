***Table 3.2: The relationship types used in the DPI-H reference architecture and what they represent***

| **ArchiMate relationship** | **Relationship type** | **What it represents** |
| --- | --- | --- |
| ![Realises](media/image14-rot90.png) | **Realises** | A capability is *realised* by the components and services that provide it |
| ![Composes](media/image15-rot90.png) | **Composes** | A component is *composed* of the functions and data objects it contains |
| ![Serves](media/image16-rot90.png) | **Serves** | A service *serves* the stakeholders and other elements that use it |
| ![Accesses](media/image17-rot270.png) | **Accesses** | A component *accesses* the data objects it reads or writes |
