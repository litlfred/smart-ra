The LIMR provides the structural layer of the semantic governance infrastructure, complementing the meaning layer provided by the Terminology Service. Where the TS answers the question 'what does this code mean?', the LIMR answers the question 'what fields does this data object contain, which are mandatory, what are their data types, and which terminology value sets bind to them?' A data element's cardinality, optionality, and relationships to other elements are properties of the LIMR; the permitted values within that element — and what those values mean — are properties of the TS. Neither is sufficient without the other.
