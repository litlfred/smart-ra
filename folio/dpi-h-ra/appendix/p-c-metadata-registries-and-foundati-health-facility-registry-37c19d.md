The following table defines the minimum dataset for a facility record in the Health Facility Registry. It draws on the WHO/USAID Master Facility List Resource Package (WHO, 2019) \cite{who-2019-mfl-resource-package}, the WHO Geolocated Health Facilities Data initiative minimum data elements (Name, Type, Location, Unique ID) \cite{who-global-health-facilities-database}, and expert feedback. The dataset is divided into a signature domain (core identity attributes) and a service domain (operational and service attributes). All signature domain elements marked Mandatory should be present for a record to be published as active.
