- **WHO ICD API and local deployments —** WHO services exposing ICD-11 Foundation and MMS content, identifiers, releases, search, and coding-related information. The API can be accessed through WHO-hosted services or suitable local deployments, including operation without a continuous external connection. It provides a concrete implementation route for an ICD-11-based semantic service. Implementers should declare the supported content, release, language, and operations. The separately documented WHO FHIR interface is under active development; implementations relying on it should declare its FHIR version, release coverage, publication status and tested operations at the time of implementation. \cite{who-icd-api,who-icd-api-local-deployment,who-icd-api-fhir-support}
- **WHO ICD-11 Coding Tool and Embedded Coding Tool —** tools supporting selection of ICD-11 concepts and applicable coding detail within clinical applications. An implementation should select the appropriate coding workflow and retain its resulting identifiers and expressions. A simplified search interface should not be represented as providing the full medical-coding workflow. \cite{who-icd11-embedded-coding-tool}
- **Snowstorm —** an open-source, FHIR-conformant terminology server used by national terminology services to host SNOMED CT and national extensions. \cite{snowstorm}
- **Ontoserver** **—** a FHIR-conformant terminology server adopted as a national terminology service in Australia and used in several other jurisdictions. \cite{ontoserver}
- **HL7 FHIR reference terminology service (tx.fhir.org) —** the reference implementation of the FHIR Terminology Service specification, widely used for testing and reference. \cite{tx-fhir-org}
- **openEHR** **Clinical Knowledge Manager —** an international, peer-reviewed repository of archetypes and templates supporting local adaptation of globally curated models. \cite{openehr-ckm}
- **National FHIR profile registries —** country-specific implementation guides and profiles (for example, Simplifier-based national registries), maintaining canonical structural definitions.
