All other DPI-H components that define structured data — the registries, the HMIS, the PHSP — reference the LIMR for their data element definitions. The LIMR's canonical registry of data elements is what enables the reference architecture to specify data requirements in a way that is structurally consistent across components. Without a LIMR, each component's data requirements exist in isolation; with a LIMR, they are part of a governed, coherent national health data model.
