The Client Registry schema — the logical structure defining which demographic attributes are stored and how they are typed, constrained, and related — is a concern of the Logical Information Model Repository. The LIMR holds the canonical model; the Client Registry implements it. Changes to the schema should be proposed, reviewed, and approved through the LIMR's governance process before being implemented. The Terminology Service provides the coded value sets for key attributes such as sex, gender, administrative territory, language, and relationship type.
